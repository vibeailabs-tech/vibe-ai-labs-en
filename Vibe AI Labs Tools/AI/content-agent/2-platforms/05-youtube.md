# YouTube

## Platform DNA
- Long-form video. sweet spot is 8-12 minutes for the algorithm
- Vibe: educational, structured, SEO-driven. YouTube is basically a search engine — people come here looking for answers
- Audience: mix of [[03-builders]] and [[04-casual]], but they're investing 8+ minutes so they're more committed than scrollers
- Evergreen content lives here. a good video gets views for years

## Content Rules
- TITLE IS EVERYTHING. SEO-optimized, curiosity-driven, specific. "How to Build an AI Content System (Step-by-Step)" not "My Content Strategy"
- Thumbnail: bold text, your face (if personal brand), contrasting colors. thumbnail and title together determine ~80% of clicks
- Match [[02-brand-voice]] but more structured. see [[01-platform-tone]]
- Use [[01-hooks]] in the first 30 seconds — the YouTube hook is basically a spoken version of your best written hook
- Structure with clear sections. use YouTube chapters

---

## Pre-Writing Questions
Answer these before writing the outline:

1. What keyword is someone searching when they need this video?
2. What does the viewer know at the END that they didn't know at the START?
3. Can you deliver on the title's promise in 8-12 minutes?
4. Is there something to SHOW on screen? (YouTube rewards demos and walkthroughs)
5. What is the ONE CTA at the end — subscribe, download, or watch next?

If the title doesn't pass this test: "Would I click this if I saw it in search?" — rewrite it.

## Video Templates

### Template A — Tutorial / How-To
```
Title: "How to [achieve outcome] (Step-by-Step)"

[HOOK — 0:00-0:30]
State the result first: "By the end of this video you'll be able to [outcome]."
Tease what's coming: "I'm going to show you exactly how I [impressive claim]."

[CONTEXT — 0:30-2:00]
Why this matters. What most people get wrong. Why your approach is different.

[MAIN CONTENT — 2:00-9:00]
Step 1: [title] — [explanation + demo]
Step 2: [title] — [explanation + demo]
Step 3: [title] — [explanation + demo]
(3-5 steps max, each with its own timestamp)

[RECAP + CTA — 9:00-10:00]
"Here's what we covered: [3 bullet recap]"
"If this helped, [subscribe / watch this next / grab the template]"
```

---

### Template B — Deep Dive / Breakdown
```
Title: "The [Topic] System That [Result] (Full Breakdown)"

[HOOK — 0:00-0:30]
Lead with the result or surprising insight

[PROBLEM — 0:30-1:30]
What's broken about how most people approach this

[THE SYSTEM — 1:30-9:00]
Walk through the full system, component by component
Show it working in real time

[RESULTS + PROOF — 9:00-10:00]
Real numbers, real outcomes
CTA
```

## Good vs Bad

### ❌ Bad title — vague, no keyword, no reason to click
```
"My Content Strategy for 2024"
"Thoughts on AI Tools"
"Weekly Vlog #47"
```

### ✅ Good title — specific, keyword-rich, promises an outcome
```
"How to Run 10 Social Media Accounts with AI (No Content Team)"
"The Exact System I Use to Repurpose 1 Post into 8 Platforms"
"How I Automated My Entire Content Workflow in One Weekend"
```

### ❌ Bad hook — slow, no promise
```
"Hey everyone, welcome back. So today I wanted to talk about 
something I've been thinking about lately, which is content 
creation and AI..."
```

### ✅ Good hook — fast, specific, creates curiosity
```
"I run 10 social media accounts. I don't write a single post manually.
In the next 10 minutes I'm going to show you the exact system —
every file, every step, everything."
```

## SEO Rules
- Title: primary keyword, natural phrasing, under 60 chars
- Description: first 2 lines visible before "show more" — put hook and key links there. full description 200-500 words
- Tags: 5-10 relevant, mix broad and specific
- Chapters: timestamps in description for each section

---

## Posting Strategy
- Frequency: 1-2x/week
- Consistency matters way more than frequency on YouTube
- Best days: Tuesday, Thursday, Saturday
- See [[04-scheduling]]
