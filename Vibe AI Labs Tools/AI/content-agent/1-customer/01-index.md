# Content Skill Graph — Command Center

## 1. Identity

Content production system for [YOUR BRAND/NAME].
Manages 10 social media accounts from one idea input.

Brand: [YOUR NAME / BRAND]
Niche: [YOUR NICHE — e.g. "AI automation, SaaS building, and monetizing tech skills"]
Mission: Turn one topic into 10 platform-native posts that each think about the topic differently

## 2. Node Map

Every node below is a knowledge file. Read the relevant ones before executing any task. The [[wikilinks]] are clickable, follow them.

### Platforms
- [[01-x]] — short-form, hook-driven, 280 chars max, casual lowercase. post 5x/week minimum. contrarian takes and step-by-step threads
- [[02-linkedin]] — long-form narrative, professional tone, 1500+ words. post 3x/week. personal stories with business insights
- [[03-instagram]] — visual-first. 7-slide carousels with bold claim on slide 1. post 4x/week. reels for short-form video
- [[04-tiktok]] — raw, unpolished, 45-60 second screen recordings or talking head. post 5x/week. hook in first 2 seconds
- [[05-youtube]] — SEO-optimized titles, structured outlines, 8-12 minute format. post 2x/week. evergreen content focus
- [[07-threads]] — conversational, opinion-driven, casual. post 3x/week. think "X but more relaxed"
- [[08-facebook]] — community-focused, longer captions, group engagement. post 3x/week
- [[06-newsletter]] — deep-dive format, 1000-2000 words, actionable frameworks. send 1x/week

### Voice
- [[02-brand-voice]] — the core personality, values, tone markers, and vocabulary that define how we sound across ALL platforms
- [[01-platform-tone]] — how the core voice adapts per platform. same person, different room

### Engine
- [[01-hooks]] — scroll-stopping opener formulas. categorized by type: contrarian, proof, discovery, replacement, playbook. updated weekly based on performance
- [[02-repurpose]] — the repurposing chain: 1 idea → 10 outputs. defines which platform gets written first, the adaptation order, and what changes between each version
- [[04-scheduling]] — posting calendar, best times per platform, frequency rules, and batch workflow
- [[03-content-types]] — format definitions: threads, carousels, reels, long-form articles, short takes, video scripts, newsletters

### Audience
- [[03-builders]] — primary audience. indie hackers, AI engineers, SaaS founders, freelancers monetizing tech skills. they want actionable playbooks, real numbers, and tools they can use today
- [[04-casual]] — secondary audience. curious about AI/tech but not building yet. they want inspiration, simplified explanations, and "wow I can do this too" moments

## 3. Execution Instructions

When given a topic:

1. Check if the topic aligns with our niche. If not, reject it
2. Read [[02-brand-voice]] for core personality
3. Read [[01-hooks]] and select the best hook formula for the topic
4. Read [[02-repurpose]] for the production chain order
5. Write for the FIRST platform in the chain (usually [[01-x]])
6. For each subsequent platform, read that platform's node and [[01-platform-tone]] to adapt. don't just reformat, RETHINK the angle, structure, hook, and format for that specific platform
7. Apply [[04-scheduling]] rules for timing and frequency
8. Output one native post per platform, each post ready to publish

CRITICAL RULE: The output is NOT 10 copies of the same text reformatted for each platform. It's 10 pieces that each THINK about the topic differently. Same topic, different angle, hook, voice, structure, and format per platform.
