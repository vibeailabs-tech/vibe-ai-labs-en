# brand.md — Master Schema
> This is the standard template for all client brand files.
> Every skill in the Brand Foundation Agent writes to this file.
> Every other agent in the system reads from this file before executing.

---

## Rules
- Each skill owns specific sections — never overwrite sections owned by other skills
- If a section is not yet filled, leave it as `[To be filled]`
- Always update the "Last updated" date when writing
- Write in the client's preferred language (Vietnamese / English / Both)
